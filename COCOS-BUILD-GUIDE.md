# Инструкция по правильной настройке билда в Cocos Creator

## Шаг 1: Откройте настройки билда

1. В Cocos Creator откройте меню **Project → Build**
2. Или нажмите `Cmd+Shift+B` (Mac) / `Ctrl+Shift+B` (Windows)

## Шаг 2: Выберите платформу "Web Desktop"

1. В выпадающем списке **Platform** выберите **Web Desktop**
2. Убедитесь, что выбрана правильная платформа

## Шаг 3: Настройте параметры билда

### Основные настройки:

1. **Build Path** (путь билда):
   - Должен быть: `build/web-desktop`
   - Или: `./build/web-desktop` (относительно корня проекта)

2. **Start Scene** (стартовая сцена):
   - Выберите вашу главную сцену: `assets/Game.scene`

3. **MD5 Cache** (кэш MD5):
   - ✅ **Включите** (рекомендуется для продакшена)
   - Это добавляет хеши к именам файлов для кэширования

4. **Source Maps** (карты исходников):
   - ⚠️ Для продакшена: **Выключите** (уменьшает размер билда)
   - Для разработки: можно включить

5. **Merge JSON** (объединение JSON):
   - ✅ **Включите** (уменьшает количество HTTP-запросов)

6. **Compress Texture** (сжатие текстур):
   - ✅ **Включите** (уменьшает размер билда)

### Дополнительные настройки:

1. **Polyfills** (полифиллы):
   - ✅ Оставьте включенным (нужно для совместимости)

2. **Separate Engine** (отдельный движок):
   - ⚠️ Обычно **выключено** (движок встроен в билд)
   - Если включено - убедитесь, что `cocos-js` папка включена в деплой

3. **Inline SpriteFrames** (встроенные спрайты):
   - ⚠️ Обычно **выключено** (спрайты загружаются отдельно)
   - Если включено - все спрайты будут встроены в JS (большой размер)

## Шаг 4: Проверьте настройки шаблона

1. В настройках билда найдите раздел **Template** (Шаблон)
2. Убедитесь, что выбран шаблон: `web-desktop`
3. Шаблон находится в: `build-templates/web-desktop/index.ejs`

## Шаг 5: Выполните билд

1. Нажмите кнопку **Build** (Собрать)
2. Дождитесь завершения билда
3. Проверьте, что в папке `build/web-desktop/` появились все файлы:
   - ✅ `index.html`
   - ✅ `index.js`
   - ✅ `application.js`
   - ✅ `style.css`
   - ✅ `src/` (папка с JS файлами)
   - ✅ `assets/` (папка с ресурсами)
   - ✅ `cocos-js/` (папка с движком, если Separate Engine включен)

## Шаг 6: Проверьте структуру билда

После билда проверьте, что структура правильная:

```
build/web-desktop/
├── index.html          ✅ Главный HTML файл
├── index.js            ✅ Точка входа
├── application.js      ✅ Логика приложения
├── style.css           ✅ Стили
├── favicon.ico         ✅ Иконка
├── src/                ✅ JS файлы и настройки
│   ├── polyfills.bundle.js
│   ├── system.bundle.js
│   ├── import-map.json
│   └── settings.json
├── assets/             ✅ Ресурсы игры
│   ├── main/
│   └── internal/
└── cocos-js/           ✅ Движок (если Separate Engine включен)
    ├── cc.js
    └── ...
```

## Шаг 7: Проверьте index.html

Откройте `build/web-desktop/index.html` и убедитесь, что:

1. ✅ Все пути к файлам относительные (начинаются с `./` или без слеша)
2. ✅ Все скрипты загружаются правильно
3. ✅ Нет абсолютных путей типа `/src/...` (должно быть `./src/...`)

## Шаг 8: Локальное тестирование

Перед деплоем протестируйте локально:

### Вариант 1: Простой HTTP сервер

```bash
cd build/web-desktop
python3 -m http.server 8000
# или
npx serve .
```

Затем откройте: `http://localhost:8000`

### Вариант 2: Проверка в браузере

1. Откройте `build/web-desktop/index.html` в браузере
2. Откройте DevTools (F12)
3. Проверьте консоль на ошибки:
   - ❌ 404 ошибки (файлы не найдены)
   - ❌ CORS ошибки
   - ❌ Ошибки загрузки WASM

## Шаг 9: Подготовка к деплою

### Убедитесь, что все файлы в git:

```bash
git add build/web-desktop/
git status  # Проверьте, что все файлы добавлены
```

### Проверьте .gitignore:

Убедитесь, что в `.gitignore` есть:
```
build/*
!build/web-desktop/
```

Это игнорирует все в `build/`, кроме `web-desktop/`.

## Шаг 10: Настройки Vercel

После правильного билда настройте Vercel:

1. **Root Directory**: `build/web-desktop`
2. **Output Directory**: `.` (точка, toggle ON)
3. **Build Command**: OFF (билд уже готов)
4. **Install Command**: OFF (не нужен)

## Частые проблемы и решения

### Проблема 1: Файлы не найдены (404)

**Причина**: Неправильные пути в `index.html` или файлы не закоммичены

**Решение**:
- Проверьте, что все пути относительные
- Убедитесь, что все файлы в git: `git ls-files build/web-desktop/ | wc -l`

### Проблема 2: WASM не загружается

**Причина**: Неправильные CORS заголовки или пути

**Решение**:
- Проверьте `vercel.json` - должны быть правильные headers для `.wasm`
- Убедитесь, что `cocos-js/` папка включена в деплой

### Проблема 3: Игра не запускается

**Причина**: Ошибки в консоли браузера

**Решение**:
- Откройте DevTools (F12)
- Проверьте консоль на ошибки
- Проверьте Network tab - какие файлы не загружаются

### Проблема 4: Билд слишком большой

**Решение**:
- Включите **Compress Texture**
- Включите **MD5 Cache**
- Выключите **Source Maps** для продакшена
- Оптимизируйте размеры текстур и аудио

## Рекомендуемые настройки для продакшена

```
✅ MD5 Cache: ON
✅ Merge JSON: ON
✅ Compress Texture: ON
❌ Source Maps: OFF
❌ Separate Engine: OFF (если не нужен)
❌ Inline SpriteFrames: OFF
```
