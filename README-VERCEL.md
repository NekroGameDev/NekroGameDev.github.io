# Деплой на Vercel

## Быстрый старт

1. Убедитесь, что у вас создан билд:
   ```
   Откройте Cocos Creator → Project → Build... → Web Desktop
   ```

2. Установите Vercel CLI (если еще не установлен):
   ```bash
   npm i -g vercel
   ```

3. Задеплойте проект:
   ```bash
   vercel
   ```

4. Или через веб-интерфейс:
   - Зайдите на https://vercel.com
   - Импортируйте репозиторий
   - Укажите:
     - Root Directory: `build/web-desktop`
     - Build Command: (оставьте пустым или `echo 'Build exists'`)
     - Output Directory: `.` (точка)

## Структура файлов

- `vercel.json` - конфигурация Vercel с правилами для SPA
- `.vercelignore` - файлы, которые нужно игнорировать при деплое
- `build/web-desktop/` - папка с билдом Cocos Creator

## Решение проблем

### Ошибка NOT_FOUND

Если получаете ошибку NOT_FOUND:
1. Убедитесь, что папка `build/web-desktop` существует
2. Проверьте, что в `vercel.json` указан правильный `outputDirectory`
3. Убедитесь, что все файлы билда присутствуют

### Ресурсы не загружаются

Если ресурсы (изображения, звуки) не загружаются:
1. Проверьте консоль браузера на ошибки CORS
2. Убедитесь, что headers в `vercel.json` настроены правильно
3. Проверьте, что пути к ресурсам относительные (начинаются с `./`)
