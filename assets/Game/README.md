# Runner Game - Cocos Creator Implementation

Реализация игры-раннера на Cocos Creator 3.8.8

## Структура проекта

```
assets/Game/
├── images/          # Графические ассеты (персонаж, препятствия, фон)
└── scripts/         # TypeScript компоненты
    ├── GameManager.ts      # Основной менеджер игры
    ├── PlayerController.ts # Управление персонажем
    ├── HealthUI.ts         # UI здоровья (сердечки)
    ├── TutorialUI.ts       # UI туториала
    └── MuteButton.ts       # Кнопка выключения звука
```

## Компоненты

### GameManager
Основной компонент управления игрой:
- Управление состоянием игры (Start, Playing, Over)
- Подсчет очков
- Спавн препятствий
- Проверка коллизий
- Система здоровья
- Туториал

### PlayerController
Управление персонажем:
- Прыжок по тапу/клику
- Физика прыжка (tween анимация)
- Обработка ввода

### HealthUI
Отображение здоровья:
- Динамическое создание сердечек
- Плавное исчезновение при потере здоровья
- Анимация масштабирования

### TutorialUI
Туториал:
- Показ подсказки при приближении к первому препятствию
- Автоматическое скрытие через 3 секунды
- Плавная анимация появления/исчезновения

### MuteButton
Кнопка звука:
- Переключение звука вкл/выкл
- Смена иконки

## Настройка сцены

1. Создайте Canvas с разрешением 375x812 (мобильный формат)
2. Добавьте GameManager на корневой узел
3. Создайте структуру:
   - Background (Sprite с фоном)
   - Player (Node с PlayerController и Sprite)
   - ObstacleContainer (Node для препятствий)
   - UI (Node с дочерними элементами):
     - ScoreLabel (Label)
     - HealthUI (Node с HealthUI компонентом)
     - TutorialUI (Node с TutorialUI компонентом)
     - MuteButton (Button с MuteButton компонентом)
     - StartScreen (Node с кнопкой Start)
     - GameOverScreen (Node с кнопкой Restart)

## Настройка ассетов

1. Импортируйте изображения в `assets/Game/images/`:
   - `6feafd658ed5.png` - персонаж
   - `518cb2af8bcd.png` - препятствие
   - `00d671b05eb1.webp` - фон

2. Создайте SpriteFrame из изображений
3. Назначьте их в компонентах:
   - GameManager: playerSprite, obstacleSprite, backgroundSprite
   - HealthUI: heartSprite (можно использовать эмодзи или спрайт)
   - MuteButton: muteIcon, unmuteIcon

## Игровая механика

- Персонаж автоматически бежит вперед
- Тап/клик для прыжка
- Препятствия спавнятся случайным образом
- За каждое пройденное препятствие +10 очков
- Скорость игры постепенно увеличивается
- Система здоровья: 3 сердца, игра заканчивается при потере всех
- Туториал появляется только при приближении к первому препятствию
